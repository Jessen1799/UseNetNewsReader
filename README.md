# NNTP Project D25

School assignment to learn how to program a client with NNTP protocol.

## Description

I built a simple news reader. The idea is that us students had the opportunity to learn to code a client and try to connect to a server while the server is using NTTP protocol.
It was difficult but very fun. I managed to implement all priority 1 use cases but did not implemement all usecases with higher priorities since it was too much to handle.
